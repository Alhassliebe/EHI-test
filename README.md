# Edinburgh Handedness Inventory: Online Test

A one-page web version of the Edinburgh Handedness Inventory (Oldfield, 1971), the classic questionnaire used in psychology and neuroscience to measure handedness.

**Try it:** https://alhassliebe.github.io/EHI-test/

You go through everyday actions (writing, throwing, using scissors and so on) and say which hand you use for each. The answers are turned into a Laterality Quotient, LQ = (R − L) / (R + L) × 100, which places you on a scale from strongly left-handed to strongly right-handed. Everything runs in the browser, with no sign-up and no data sent anywhere.

Plain HTML, CSS and JavaScript in a single `index.html`, hosted on GitHub Pages.

Reference: Oldfield, R. C. (1971). The assessment and analysis of handedness: The Edinburgh inventory. *Neuropsychologia*, 9(1), 97–113.
